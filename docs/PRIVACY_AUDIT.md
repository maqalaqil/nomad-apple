# Privacy audit — 5 November 2026

Scope: the current NOMAD Apple source for iPhone, iPad and native Mac, its restored WebTools distributions, and available native dependency binaries. This is a source/configuration and bounded binary-symbol audit, not an interception test of every feature or a completed App Store privacy questionnaire. No user content, device installation or server configuration was changed.

The app has local data stores and intentional internet features. No app-operated content-upload, advertising or analytics service was found in the native integration. That does **not** establish that nothing leaves the device: content downloads, OPDS queries, operating-system services, explicit exports and external links have separate data flows.

## Bundled dependency findings

- **CyberChef v11.5.0**, **IT Tools v2024.10.22-7ca5933**, **Excalidraw 0.18.1**: full bundled local assets are loaded through [CyberChefView](../apple/App/Tools/CyberChefView.swift), with native HTTP(S)/WebSocket block rules, local navigation checks and generated CSP. Failure to create the rule list prevents loading. Normal browser storage is persistent, so recipes, preferences and drawings can survive relaunch. File access goes through a picker; exports use native sharing/save panels. The web UI may request camera/microphone permission for the recording tool the user opens.
- IT Tools **contains `plausible-tracker`**, so “no analytics code in dependencies” would be false. The corresponding source's `src/config.ts` defaults `isTrackerEnabled` to false; the pinned built `assets/index-f8ba620c.js` has no `VITE_TRACKER_ENABLED` override in `loadEnv` and installs the no-op tracker. Remote requests are blocked separately. Recheck this flag after every bundle update. Excalidraw contains translated Sentry-related strings; no Sentry endpoint or initialization was found in the examined distribution. A string match alone is not evidence of collection.
- **Perseus 78.2.0**: [integration](../apple/scripts/fetch-perseus/main.jsx) supplies a no-op analytics callback; assets/Graphie use local package routes. [Native host](../apple/App/Education/CoursePerseusView.swift) uses nonpersistent WebKit storage and HTTP(S)/WebSocket blocking. Native answer/progress persistence is intentional. Imported HTML5 course packages have the same network restrictions and a separate bounded progress bridge.
- **MapLibre 4.7.1 / PMTiles 4.4.0 / Protomaps basemaps 5.7.0**: generated assets are local; [map integration](../apple/scripts/fetch-map-assets/main.js) adds navigation and scale controls, not geolocation. Upstream geolocation code remains in the distribution but is not invoked by this integration.
- **CoreKiwix/libzim/Xapian and llama**: available archives have no supplied privacy manifest. CoreKiwix contains file-metadata and networking symbols, while the examined linked Debug app did not retain the archive's `connect`/`socket` imports. [NomadZIMArchive.mm](../apple/App/Library/NomadZIMArchive.mm) accepts file URLs and reads/searches local archives. llama's observed `clock_gettime`/hardware-query imports do not independently establish transmission. Symbol inspection does not prove the behavior of every code path or final Release slice.

No listed advertising SDK, native analytics client or advertising-ID access was found. Compare **every final embedded/repackaged dependency** against Apple's current [SDK manifest/signature requirements](https://developer.apple.com/support/third-party-SDK-requirements/); an app manifest does not replace a required SDK manifest/signature. Do not infer runtime privacy from an upstream website's privacy statement. Existing host smoke tests demonstrate selected blocked requests, not complete packet-capture coverage or proof against every browser API.

## Permissions, clipboard and retention

The generator supplies Face ID, camera and microphone purpose strings. Mac entitlements permit sandboxed selected-file access, outgoing networking and camera/audio input; a permission entitlement is not a claim that a feature has been exercised. No contacts, photo-library-wide, location or ATT request was found. Imports can still include photos selected as files. Inventory photo imports strip original metadata through re-encoding; other imported documents may retain metadata.

[NomadClipboard](../apple/App/Platform/PlatformSupport.swift) uses the ordinary OS clipboard. [VaultClipboard](../apple/App/Vault/VaultClipboard.swift) adds local-only, 45-second expiry on iOS/iPadOS; on Mac it clears an unchanged copy after 45 seconds only while the app runs, and cannot prevent other apps or Universal Clipboard from reading it. Do not promise all copies remain on one device.

Deleting a source record need not erase an already exported file, backup, restore rollback copy, conversation citation, search index or browser draft. Mac app-bundle removal is not an app-data wipe. Keychain items may outlive app removal. Privacy instructions must not promise complete secure deletion by uninstalling.
